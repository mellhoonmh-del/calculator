# Streamlit 계산기 프로그램

Streamlit을 활용하여 웹 브라우저에서 간편하게 사용할 수 있는 두 정수 연산 계산기입니다.

## 주요 기능
- **직관적인 인터페이스**: 첫 번째 정수, 연산자, 두 번째 정수를 각각 한 줄씩 입력받아 실시간으로 계산 결과를 출력합니다.
- **예외 처리**: 
  - 정수가 아닌 값이 입력된 경우 오류 메시지를 표시합니다.
  - 0으로 나누기를 시도할 경우 예외 처리를 수행합니다.
  - 허용된 연산자(`+`, `-`, `*`, `/`) 외의 기호가 입력된 경우 오류를 발생시킵니다.
- **간결한 구조**: 클래스를 사용하지 않고 직관적인 코드로 작성되었습니다.
